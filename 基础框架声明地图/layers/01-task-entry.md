# 1. 任务入口层

## 适用任务

把人类提出的目标转化为 Agent 可执行的工程任务。

## 先读文件

- `00-agent-entry.md`
- `protocols/task-routing.md`
- `templates/agent-task-brief.md`

## Agent 应做

- 提取目标、范围、约束和验收标准。
- 判断任务是否需要读代码、改代码、运行命令或请求审批。
- 将模糊需求拆成可执行步骤。
- 对高风险或不可逆操作先请求确认。

## Agent 不应做

- 在需求仍明显矛盾时直接大范围改动。
- 把用户没有要求的重构混入主要任务。
- 跳过验收标准直接执行。

## 输入

- 用户自然语言任务。
- 项目现有文件。
- 历史说明文档。

## 输出

- 任务类型。
- 阅读路径。
- 执行计划。
- 验收标准。

## 完成标准

Agent 能明确说明“下一步要读什么、改什么、如何验证”。

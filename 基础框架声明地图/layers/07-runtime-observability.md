# 7. 运行观测层

## 适用任务

上线后问题发现、日志分析、指标观察、链路追踪和事故复盘。

## 先读文件

- `layers/02-project-knowledge.md`
- `layers/06-cicd-delivery.md`
- `governance/safety-boundaries.md`

## Agent 应做

- 根据症状定位相关服务、模块和日志。
- 区分代码缺陷、配置问题、资源问题和外部依赖问题。
- 为修复提供观测证据。
- 在事故后沉淀复盘和预防措施。

## Agent 不应做

- 未授权访问生产敏感数据。
- 把用户数据复制进普通日志或文档。
- 在没有回滚依据时建议冒险发布。

## 输入

- 错误日志。
- 指标。
- 告警。
- 用户反馈。
- 版本变更记录。

## 输出

- 问题时间线。
- 根因假设。
- 验证证据。
- 修复或回滚建议。

## 完成标准

Agent 能把运行现象映射到可检查的工程位置，并提出可验证的处理方案。

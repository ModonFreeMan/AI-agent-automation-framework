# 3. 开发环境层

## 适用任务

安装依赖、启动本地服务、运行脚本、调试代码。

## 先读文件

- `layers/02-project-knowledge.md`
- 项目依赖文件，例如 `package.json`、`pyproject.toml`、`requirements.txt`、`pom.xml`。

## Agent 应做

- 识别项目使用的包管理器、运行时和启动命令。
- 优先使用项目已有脚本。
- 记录必要的环境变量，但不暴露密钥。
- 在命令失败时区分环境问题、依赖问题和代码问题。

## Agent 不应做

- 未确认前全局安装依赖。
- 未经允许修改系统级配置。
- 把密钥写入仓库。

## 输入

- 依赖清单。
- 环境变量说明。
- 本地启动脚本。

## 输出

- 本地启动命令。
- 调试命令。
- 依赖安装说明。
- 常见环境故障处理。

## 完成标准

Agent 能在本地复现项目运行或清楚说明阻塞原因。

# 2. 项目知识层

## 适用任务

理解项目结构、业务概念、模块边界和架构约束。

## 先读文件

- `README.md`
- `agent-locator.yaml`
- 项目根目录下的 README、配置文件、依赖文件和源码入口。

## Agent 应做

- 识别技术栈、入口文件、模块分层和关键配置。
- 维护业务术语和代码路径之间的映射。
- 优先遵循项目已有风格和抽象。
- 发现知识缺口时补充文档或标记待确认。

## Agent 不应做

- 在不了解模块边界时跨目录大改。
- 用猜测替代项目事实。
- 引入与现有技术栈不一致的新框架。

## 输入

- 文件树。
- 源码。
- 配置。
- 业务说明。

## 输出

- 项目结构摘要。
- 关键模块定位。
- 依赖与约束说明。
- 术语到路径的映射。

## 完成标准

Agent 能从一个业务词或技术词定位到相关文件和说明。

# 8. 治理与安全层

## 适用任务

限制 Agent 行为，管理权限、审批、安全、隐私和合规要求。

## 先读文件

- `governance/safety-boundaries.md`
- `protocols/document-contract.md`

## Agent 应做

- 识别高风险操作。
- 对密钥、个人信息、生产数据和权限变更保持最小暴露。
- 将不可自动执行的操作交给人工确认。
- 记录安全相关决策。

## Agent 不应做

- 提交密钥或凭证。
- 绕过审批流程。
- 自动执行生产破坏性操作。
- 删除审计线索。

## 输入

- 权限规则。
- 数据分类。
- 审批要求。
- 风险等级。

## 输出

- 风险判断。
- 审批请求。
- 安全处理建议。
- 合规记录。

## 完成标准

Agent 在执行任务前能判断哪些事情可自动做，哪些必须等待人类确认。

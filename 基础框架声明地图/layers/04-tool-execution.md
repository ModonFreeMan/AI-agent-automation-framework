# 4. 工具执行层

## 适用任务

定义 Agent 可以调用哪些工具，以及调用工具时的权限、输入和输出。

## 先读文件

- `governance/safety-boundaries.md`
- `layers/03-dev-environment.md`

## Agent 应做

- 优先使用仓库内已有工具和脚本。
- 对文件搜索使用快速、可重复的命令。
- 对外部服务调用记录目的、参数来源和结果。
- 对需要审批的命令先说明原因。

## Agent 不应做

- 绕过权限限制调用工具。
- 在没有备份或审批时执行破坏性操作。
- 把工具输出中的敏感信息写入普通文档。

## 输入

- 可用工具列表。
- 权限边界。
- 命令参数。

## 输出

- 执行记录。
- 关键输出摘要。
- 失败原因与下一步建议。

## 完成标准

每一次工具调用都能解释“为什么需要、做了什么、结果是什么”。

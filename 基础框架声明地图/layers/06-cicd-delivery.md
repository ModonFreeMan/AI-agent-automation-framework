# 6. CI/CD 交付层

## 适用任务

构建、测试、发布、部署、回滚和处理流水线失败。

## 先读文件

- `layers/05-quality-verification.md`
- `governance/safety-boundaries.md`
- 项目 CI/CD 配置。

## Agent 应做

- 理解流水线阶段、触发条件和产物。
- 在部署前确认测试状态和审批要求。
- 处理失败时先定位失败阶段，再提出最小修复。
- 对生产部署和回滚保持人工确认边界。

## Agent 不应做

- 未经授权触发生产部署。
- 隐藏或忽略失败的质量门禁。
- 修改流水线来绕过测试。

## 输入

- CI 配置。
- 构建日志。
- 发布版本。
- 部署环境。

## 输出

- 构建结果。
- 发布说明。
- 部署状态。
- 回滚建议。

## 完成标准

交付过程可追踪、可复现，失败时能定位到具体阶段。

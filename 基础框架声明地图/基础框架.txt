AI Agent 自动化工程框架声明地图

本目录不是普通说明文档集合，而是给 AI Agent 使用的“工程导航层”。
任何 Agent 接到任务后，应先读取本目录中的入口与定位协议，再进入具体项目代码。

推荐读取顺序：
1. README.md
2. 00-agent-entry.md
3. agent-locator.yaml
4. protocols/task-routing.md
5. 与当前任务匹配的 layers/*.md
6. governance/safety-boundaries.md

框架总览：
├── 1. 任务入口层：人类如何给 Agent 下任务
├── 2. 项目知识层：Agent 如何理解项目
├── 3. 开发环境层：Agent 在哪里写代码、运行代码
├── 4. 工具执行层：Agent 可以调用哪些工具
├── 5. 质量验证层：Agent 如何证明代码没问题
├── 6. CI/CD 交付层：代码如何自动构建、测试、部署
├── 7. 运行观测层：上线后如何发现问题
└── 8. 治理与安全层：如何限制 Agent 不乱改、不乱部署

设计原则：
- 文件名必须稳定，便于 Agent 用路径直接定位。
- 每个文档必须声明“适用任务”“先读文件”“输出产物”。
- 面向自动化执行，不写空泛愿景。
- 允许后续项目把本目录复制到任意代码仓库根目录。

# Agent 工作入口

## 适用任务

所有进入本仓库的 AI Agent 任务。

## 先读文件

1. `agent-locator.yaml`
2. `protocols/task-routing.md`
3. `governance/safety-boundaries.md`
4. 与任务类型匹配的 `layers/*.md`

## 默认工作流程

1. 识别用户任务类型：需求、修复、重构、测试、部署、观测、文档、治理。
2. 读取 `agent-locator.yaml`，找到对应层级文档。
3. 检查安全边界，确认是否允许自动执行。
4. 读取项目知识层，理解目录、模块、依赖和约束。
5. 制定最小变更范围。
6. 执行修改或生成说明。
7. 运行与风险匹配的验证。
8. 输出变更摘要、验证结果和剩余风险。

## 自动构建任务入口

如果用户任务是“根据需求文档自动构建工程、代码、测试、配置或交付产物”，Agent 应进入：

1. `../自动化构建工程/requirements/current-requirement.md`
2. `../自动化构建工程/build-flow/00-build-entry.md`
3. `../自动化构建工程/build-flow/build-pipeline.yaml`

自动构建任务必须以需求文档为唯一任务源，并在 `../自动化构建工程/logs/` 记录阶段过程。

## Agent 输出要求

每次任务完成后，Agent 应说明：

- 修改了哪些文件。
- 为什么这样改。
- 已执行哪些验证。
- 哪些事项没有验证或仍需人工确认。

## 缺失信息处理

如果定位文档不存在或内容不足，Agent 应优先在本目录补充说明，再继续工程任务。

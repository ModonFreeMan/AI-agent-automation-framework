# 当前用户需求文档

## 需求状态

status: ready

## 用户目标

构建一个 Python 命令行待办事项工具。

## 背景

用户希望通过命令行管理本地待办事项。不需要数据库，不需要 Web 页面，数据保存在本地 JSON 文件中。

## 功能需求

- 可以添加待办事项。
- 可以查看所有待办事项。
- 可以标记待办事项完成。
- 可以删除待办事项。
- 数据保存在本地 `todo-data.json`。

## 非功能需求

- 性能：面向本地少量数据。
- 安全：不涉及敏感信息。
- 兼容性：Python 3.10+。
- 可维护性：代码结构清晰，包含基础测试。

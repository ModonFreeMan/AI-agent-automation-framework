# 自动构建验收清单

## 需求一致性

- [ ] 实现内容对应 `requirements/current-requirement.md`。
- [ ] 没有加入需求外的大范围改动。
- [ ] 不在范围内的事项已明确说明。

## 工程完整性

- [ ] 目标工程结构清晰。
- [ ] 必要配置文件已创建或更新。
- [ ] 入口文件、运行方式和依赖说明明确。
- [ ] 文档能指导下一位 Agent 或工程师继续工作。

## 质量验证

- [ ] 已运行相关测试。
- [ ] 如果无法运行测试，已说明原因。
- [ ] 已检查关键功能路径。
- [ ] 已记录剩余风险。

## 安全边界

- [ ] 未写入密钥、令牌、密码。
- [ ] 未执行未经确认的生产操作。
- [ ] 未删除无关文件。
- [ ] 涉及敏感数据或高风险操作时已停止并请求人工确认。

## 产物归档

- [ ] 构建结果或路径已写入 `artifacts/`。
- [ ] 阶段日志已写入 `logs/`。
- [ ] 最终摘要可复现本次构建过程。

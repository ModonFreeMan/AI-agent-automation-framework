# Agent 自动构建执行手册

## 运行前

Agent 必须先读取：

- `../requirements/current-requirement.md`
- `build-pipeline.yaml`
- `../../基础框架声明地图/governance/safety-boundaries.md`

## 执行规则

- 需求文档为空或状态为 `draft` 时，只能做需求检查和任务拆解，不应直接构建生产级产物。
- 需求状态为 `ready` 且验收标准明确时，可以进入实现阶段。
- 涉及生产、密钥、隐私、删除、迁移、付费服务的事项必须等待人工确认。
- 每个阶段完成后，应在 `logs/` 下记录阶段结果。
- 构建产物应放入 `artifacts/` 或记录实际产物路径。

## 推荐阶段记录格式

```markdown
# 阶段编号 - 阶段名称

## 输入

- 已读取的文件。

## 执行摘要

- 做了什么。

## 输出

- 生成或修改了什么。

## 验证

- 如何确认阶段完成。

## 风险与阻塞

- 剩余问题。
```

## 最终响应格式

Agent 完成自动构建后，应输出：

- 需求摘要。
- 构建范围。
- 修改文件。
- 验证结果。
- 产物路径。
- 未完成事项。

# 自动构建入口

## 适用任务

当用户要求 Agent 根据需求文档自动构建代码、配置、测试、文档或交付产物时使用。

## 先读文件

1. `../requirements/current-requirement.md`
2. `build-pipeline.yaml`
3. `agent-runbook.md`
4. `../validation/acceptance-checklist.md`
5. `../../基础框架声明地图/00-agent-entry.md`
6. `../../基础框架声明地图/governance/safety-boundaries.md`

## 总流程

1. 读取需求文档。
2. 判断需求是否足够执行。
3. 生成构建任务简报。
4. 定位或创建目标工程工作区。
5. 执行构建阶段。
6. 运行验证阶段。
7. 汇总产物、日志和剩余风险。

## 自动执行条件

只有同时满足以下条件时，Agent 可以自动进入构建：

- 需求目标明确。
- 期望产物明确。
- 验收标准明确或可以从需求中推导。
- 不涉及必须人工确认的安全边界。

## 阻塞条件

出现以下情况时，Agent 应停止自动构建并写入阻塞项：

- 需求互相矛盾。
- 缺少关键输入材料。
- 涉及生产环境、敏感数据、密钥或不可逆操作。
- 无法判断目标技术栈或构建位置。

## 输出产物

- 构建任务简报。
- 变更文件列表。
- 验证结果。
- 构建产物路径。
- 剩余风险和人工确认项。
